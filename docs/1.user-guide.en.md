## 1 What is PicoTag?

PicoTag is a QR-code-based stringing record system for badminton and tennis rackets.  
A stringer creates a unique Tag ID, generates a QR code, and attaches it to the racket (near the throat/cap).  
Later, the racket owner can scan the QR code to view the stringing record (date, tension, string, racket info, notes, etc.).

---

### 1-1 Who is it for?

- **Stringers / small studios**: create Tags, print labels, attach them to rackets, and keep cleaner records.
- **DIY stringers**: save string/tension experiments for easy comparison later.
- **Racket owners**: record your own racket info and track feel/durability over time.

---

### 1-2 Pages overview

- **Admin / Create Tags (Stringers)**: `/admin/*` (password required)
- **View a Tag (Owners)**: scanning the QR code opens `/{ID}` (or enter an ID on the home page)

---

## 2 Stringer workflow (Create a Tag)

### 2-1 Create a new Tag

1. Open your PicoTag website
2. Go to the “Create new Tag” page: `https://{your-domain}/admin/new`

---

### 2-2 Fill in the fields

Fill in the form fields on the page:

- Date (Stringing date)
- Tension (Tension)
- String (String / String info)
- Racket model (Racket / Racket info)
- Pattern (Pattern)
- Notes (Notes)
- Password features (Delete/View/Remarks password)

> Tips:  
> - Tension can be a single value, or Main/Cross (e.g. `50/48` or `25/27-25`)  
> - Some fields are free-text; use whatever format you prefer.

---

### 2-3 Generate Tag & QR Code

1. Click “Generate Tag ID & QR Code”
2. The system will generate:
   - a **Tag ID**
   - a **QR Code**
   - a sharable **URL**

---

### 2-4 How to use the label

1. Click “Download QR Code Label” to download the label image
2. Recommended placement:
   - Tennis: inside the throat area (throat inside)
   - Badminton: near the grip cap (cap)

Label suggestions:
- **18mm label tape** (simple and clean)
- **Regular printer** (print → cut → stick)

---

## 3 Scan & view

### 3-1 Scan the QR Code

Use your phone camera or a QR code app to scan the label QR code and open the Tag page.

---

### 3-2 Share & copy link

You can share the Tag URL or save it to notes:

- Click “Copy URL”
- Paste into LINE / WhatsApp / Notes, etc.

---

## 4 Special features

### 4-1 Add / update remark (Remark)

If you set a password when creating the Tag, you can add/update remarks on the Tag page:

1. Find the Remark section on the Tag page
2. Enter your remark + password, then click Save

What to write in remarks:
- How it feels after playing (repulsion/control/stiffness/vibration, etc.)
- Break location and suspected reason
- What tension/string to try next

---

### 4-2 View protection

If you don’t want anyone to view the record after scanning, enable **View protection** when creating the Tag.

---

### 4-3 Delete password

“Delete password” protects delete actions:

- If set: deleting a Tag requires the delete password
- If not set: the delete option won’t be shown on the public page. Site admins can still delete records from the admin panel.

---

### 4-4 Switch language

Use the language switcher in the top-right (e.g. `en / zh-TW / ja / ko`).

---

## 5 Admin features

> Only site admins / stringers need the admin pages.  
> Admin entry: `https://{your-domain}/admin/` (password required)

Admin pages include:

- **Create Tag**: create a new Tag
- **Reference Lists**: manage dropdown suggestion lists used when creating Tags
- **Records**: search / export all Tag records
- **System**: version & environment, D1/KV status, initialize database
- **Site**: personalize the front page (brand, intro, background, footer links)

---

### 5-1 Reference lists

Purpose: provide suggestions/autocomplete when creating Tags, reduce typing and typos.  
Path: `/admin/reference`

Lists include:

- Badminton: Racket / Pattern / String
- Tennis: Racket / Pattern / String
- Common: Machine / Stringer

Common functions:

- **Add**: add a single item
- **Batch add**: paste multiple lines to add many items quickly
- **Save**: must click Save to persist changes (*Unsaved changes* will be shown otherwise)
- **Export JSON / Import JSON**: backup or migrate lists between sites

> Tip: Reference lists are a convenience feature; not required.

---

### 5-2 Records

Purpose: browse all Tag records, search quickly, export CSV.  
Path: `/admin/records`

Common functions:

- **Search**
- **Pagination (Prev/Next)** and **Per page**
- **Export CSV**:
  - presets: This month / Last month / Last 7 days / Last 30 days
  - or custom date range (From / To)
- **Export IDs (page)**: useful for batch label printing or compiling lists

Typical columns:

- Tag ID (often with a copy button)
- Protection (View protection enabled or not)
- Tag name / Owner (depends on site settings)
- Tension
- Created (Tag creation time)
- Actions (open Tag / manage / update, etc.)

---

### 5-3 System

Purpose: verify system status, view version/environment, initialize database.  
Path: `/admin/system`

Common sections:

- **Build Info**: Version, Build Time, Project GitHub, License
- **KV Status (Lists)**: list names and item counts  
  - Lists: `RACKET`, `PATTERN`, `STRING`, `MACHINE`, `STRINGER`
- **D1 Status (Tables)**: table names and row counts  
  - Tables: `records`
- **Initialize Database**: create tables for first-time setup (usually once)
- **Environment Variables**: show key settings (e.g. `APP_ORIGIN`, `DEFAULT_LANG`, `TURNSTILE_SITEKEY`)

---

### 5-4 Site (Personalization)

Purpose: customize the front-end look/info (no code changes needed).  
Path: `/admin/site`

Common settings:

- **Website**: site/shop name
- **Intro**: heading text + description + image URL
- **Background**: background image URL
- **Footer**: footer links

Click **Save** to apply changes.

That’s it — the basic PicoTag workflow.
