# 1 PicoTag 建置指南（Cloudflare Pages + Workers KV + D1 + Turnstile）

> 這份指南會帶你從 0 開始把 PicoTag 放到 Cloudflare 上線：先部署網站，再建立 KV / D1 / Turnstile，最後進入後台初始化資料庫，完成後你會得到一個可用的 PicoTag 網站。

> 適用：Windows + PowerShell

> 本指南以 **PicoTag v1.0.2** 為主；不同版本畫面或選項可能略有差異。

> 你會需要一個 Cloudflare 帳號，並能在本機安裝 Node.js / Wrangler（後面會說明並一步一步教）。

> 如果你遇到問題或想回報 bug / 提建議，歡迎到 GitHub **Discussions**（求助/討論）或 **Issues**（Bug）留言。

## 1 註冊並登入 Cloudflare 帳號

1. 到 Cloudflare 官網 https://www.cloudflare.com/ 註冊帳號。
2. 並能成功登入 Cloudflare。

## 2 Wrangler CLI 安裝與專案上傳

在開始之前，先用一句話搞懂這兩個工具是做什麼的：

- **Node.js**：提供 `npm`（套件管理工具）與執行環境。你需要它來安裝 Wrangler。  
- **Wrangler**：Cloudflare 官方的部署工具（CLI）。用它把你電腦裡的 PicoTag 網站檔案上傳到 **Cloudflare Pages**，讓網站正式上線。

接下來我們會先安裝 Node.js，確認 `node` / `npm` 能正常使用後，再安裝並登入 Wrangler 進行部署。

### 2-1 Node.js 安裝

1. 到 Node.js 官方網站下載 LTS 版本：
   https://nodejs.org/
2. 下載 LTS 版本（例如 `v24.13.1 (LTS)`，版本號僅示意，以官網為準）
3. 安裝時一路使用「預設選項」即可
4. 安裝完成後，開啟 PowerShell，確認版本號：

```powershell
node -v
npm -v
```

![images2-1](img/2.2-1.png)

看到版本號（例如 `v20.x.x`、`10.x.x`）就代表成功。

> 若你執行 `npm -v` 出現 UnauthorizedAccess / PSSecurityException（PowerShell 權限限制），請在 PowerShell 執行：
>
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
> ```
>
> 然後 **關閉 PowerShell 再重新開啟**，再試一次 `npm -v`。

---

### 2-2 安裝 Wrangler（Cloudflare 部署工具）

#### 2-2-1 安裝與登入

在 PowerShell 執行安裝指令：

```powershell
npm i -g wrangler
```

安裝完成檢查

```powershell
wrangler -v
```

![images2-2-1_1](img/2.2-2-1_1.png)

看到版本號就代表成功。

第一次使用需要登入 Cloudflare（通常只做一次）：

```powershell
wrangler login
```

它會開啟瀏覽器讓你授權 Cloudflare 帳號。

![images2-2-1_2](img/2.2-2-1_2.png)

授權成功畫面

---

### 2-3 下載 PicoTag 程式碼壓縮檔

1. 到 GitHub 專案頁的 **Releases**，進入你要的版本（例如 **v1.0.2**）。
2. 在該版本頁面往下找到 **Assets** 區塊，下載你上傳的部署包 ZIP：  
   - **PicoTag-v1.0.2-20260226.zip**（例如下載這個）  
   - 請不要下載 GitHub 自動產生的 **Source code (zip)** / **Source code (tar.gz)**（那是 GitHub 自動打包的原始碼壓縮檔）。
3. 解壓縮到本機資料夾（例如 `C:\PicoTag`）。
4. 在 PowerShell 切換到該資料夾：

```powershell
cd C:\PicoTag
```

4. 用 `dir` 確認已在「專案根目錄」（應該看得到 `index.html`）：

```powershell
dir
```

![images2-3](img/2.2-3.png)

使用 dir 指令確認已在專案根目錄

---

### 2-4 第一次部署到 Cloudflare Pages

在專案根目錄執行：

```powershell
wrangler pages deploy . --project-name picotag-demo
```

> 小提醒：picotag-demo 只是範例名稱，你可以自行命名（命名規則請看下一小節）

接著會出現互動式提示：

- `> Create a new project` → 按 Enter
- `? Enter the production branch name:` → 直接按 Enter（用預設值即可）

![images2-4](img/2.2-4.png)

專案部署成功畫面

#### 2-4-1 專案名稱規則（project-name）

`picotag-demo` 你可以自己取，但須遵守：

- 只能用 **小寫英文字母**與數字
- 可以用 `-`（dash）
- 不要用空白、底線或大寫
- 不要以 `-` 開頭或結尾

部署成功後，Cloudflare 會給你一個預設網域：`*.pages.dev`

## 3 Cloudflare 後續設定（KV / D1 / Turnstile）

在這一章你會建立 PicoTag 需要用到的 3 個 Cloudflare 服務：

- **KV（Workers KV）**：用來存放「參考清單」這類需要快速讀取的資料（例如球拍、線材、Pattern、Machine、Stringer 的清單）。
- **D1 Database**：Cloudflare 的資料庫（SQLite），用來存放主要紀錄資料（例如每個 Tag / Records）。
- **Turnstile**：Cloudflare 的人機驗證（類似 reCAPTCHA），用來保護後台登入，避免被機器人嘗試暴力破解。

接下來會依序建立這三個服務，並在後台綁定給 PicoTag 使用。

### 3-1 取得 Pages 網域（Domains）

1. `Compute -> Workers & Pages`
2. 進入你的 Pages 專案（例如 `picotag-demo`）
3. 找到 **Domains**，你會看到類似：
   - `picotag-demo.pages.dev`

![images3-1](img/2.3-1.png)

先把這個網域記下來，後面會用到。

---

### 3-2 建立 Workers KV

1. `Storage & databases -> Workers KV`
2. 點 `Create Instance` 新增一個 KV 資料庫
3. Namespace 名稱：`picotag` 後點選 Create 完成新增。

![images3-2](img/2.3-2.png)

---

### 3-3 建立 D1 Database

1. `Storage & databases -> D1 Database`
2. 點 `Create Database` 新增一個 D1 資料庫
3. Name 名稱：`picotag` 後點選 Create 完成新增。

![images3-3](img/2.3-3.png)

---

### 3-4 建立 Turnstile

1. `Application security -> Turnstile`
2. 點 `Add widget`
3. 填：
   - `Widget name`：`picotag`
4. `Add Hostnames`：
   - `Add a custom hostname`：填你的 Pages 網域 (3-1 得到的 Domains)
     例：`picotag-demo.pages.dev`
   - 按 `Add`
5. 勾選剛加入的 Hostname，按 `Add`
6. 按 `Create`

![images3-4_1](img/2.3-4_1.png)

建立完成後會拿到：

- `Site Key`
- `Secret Key`

![images3-4_2](img/2.3-4_2.png)

> **Secret Key 不能公開**

## 4 在 Cloudflare Pages 設定網站參數（Variables / Bindings）

設定位置：`Compute -> Workers & Pages -> (你的專案) -> Settings`

在這一步我們要把「站點設定」與「資料庫/儲存服務」提供給 PicoTag 使用：

- **Variables（環境變數）**：放網站需要的設定值（例如後台密碼、網站來源網域、預設語言、Turnstile Key）。
- **Bindings（綁定）**：把 Cloudflare 的服務（D1 Database、KV）綁給 PicoTag 的程式使用，程式才能讀寫資料。

> 重要提醒：每次設定完 **Variables / Bindings** 後，必須到下一章節 **「## 5 重新部署讓設定生效」** 再部署一次，線上環境才會真的套用新的設定。

### 4-1 設定 Variables（環境變數）

到：`Variables and Secrets` → `Add`，加入以下變數：

| Type | Variable name | Value |
|---|---|---|
| `Text` | `ADMIN_PASSWORD` | `{你的後台密碼}` |
| `Text` | `APP_ORIGIN` | `{3-1 得到的 Domains}` |
| `Text` | `DEFAULT_LANG` | `{預設語言 4-1-1 說明}` |
| `Text` | `TURNSTILE_SITEKEY` | `{3-4 得到的 Site Key}` |
| `Text` | `TURNSTILE_SECRET_KEY` | `{3-4 得到的 Secret Key}` |

> 小提醒：`ADMIN_PASSWORD` 建議使用強密碼（例如至少 12 碼，包含大小寫字母、數字與符號），避免被暴力嘗試登入。

#### 4-1-1 DEFAULT_LANG 語言代碼對照（常用）

你可以用以下的語言設定：

- `en` — English
- `zh-TW` — 繁體中文(Traditional Chinese)
- `zh-CN` — 簡體中文(Simplified Chinese)
- `id` — Indonesian
- `hi` — Hindi
- `ta` — Tamil
- `ms` — Malay
- `th` — Thai
- `ja` — Japanese
- `ko` — Korean
- `vi` — Vietnamese
- `fil` — Filipino
- `da` — Danish
- `de` — German
- `fr` — French

---

### 4-2 設定 Bindings（綁定 D1 / KV）

到：`Bindings` → `Add`，分別加入：

#### 4-2-1 D1 database

- 類型：`D1 database`
- `Variable name`：`DB`
- `D1 database`：選擇剛剛在 3-3 建立的 `picotag`

#### 4-2-2 KV namespace

- 類型：`KV namespace`
- `Variable name`：`KV`
- `KV namespace`：選擇剛剛在 3-2 建立的 `picotag`

![images4](img/2.4.png)

設定完成如圖

## 5 重新部署讓設定生效

> 很重要：Pages 的 Variables / Bindings 必須要「重新部署」後，線上環境才會真的使用到新設定。

回到 PowerShell（專案根目錄）再部署一次：

```powershell
wrangler pages deploy . --project-name picotag-demo
```

## 6 設定前台與後台初始化

接下來的「前台 / 後台」是指你剛部署完成的 **PicoTag 網站頁面**（用 3-1 取得的 Domains 開啟）。  
例如你的網域是 `picotag-demo.pages.dev`  
那前台就是 `https://picotag-demo.pages.dev/`  
後台入口在 `https://picotag-demo.pages.dev/admin/` 

### 6-1 進入後台

開啟：

- `https://{你的網域}/admin/`

輸入在 `ADMIN_PASSWORD` 設定的密碼。

![images6-1](img/2.6-1.png)

---

### 6-2 初始化 D1 Database

在 `https://{your-domain}/admin/system` 找到：

- `D1 Status (Tables) -> Initialize Database`

按下去會建立資料表（第一次必做）。

---

### 6-3 初始化個人化網站訊息

進入：

- `https://{your-domain}/admin/site`

依需求填入店家資訊、網站名稱、頁尾資訊等。

---

### 6-4 建立 Reference（可選）

進入：

- `https://{your-domain}/admin/reference`

先建立常用清單（球拍型號、線材、穿線師、pattern…），未來建立 Tag 會更快。

---

## 7 建立一個 Tag 並測試功能是否正常

1. 到後台建立新 Tag：
   `https://{你的網域}/admin/new`
2. 測試以下項目：
   - 能正常產生 QR Code
   - Tag 頁面能正常開啟、顯示資料
   - `admin/records` 能看到新增紀錄
   - Reference 下拉（若有設定）能正常運作

---

以上完成後，你就能在 Cloudflare 上擁有一個自己的 PicoTag 網站
