## 1 PicoTag 是什麼

PicoTag 是一個「穿線紀錄 Tag 系統」：  
穿線師建立一個唯一 ID 的 Tag，產生 QR Code，貼在球拍拍底（throat / cap 附近），球拍主人之後只要掃描 QR Code 就能查看該次穿線資訊（日期、張力、線材、球拍、備註等）。

---

### 1-1 適合誰使用

- **穿線師 / 個人工作室**：建立 Tag、列印標籤、貼到球拍，讓服務更專業、紀錄更完整。
- **自己穿線的人**：把每次實驗的線材/張力/備註留下來，日後好比較。
- **球拍主人**：記自已的球拍資訊，方便追蹤手感與耐用度。

---

### 1-2 頁面說明

- **後台管理、建立 Tag（穿線師）**：`/admin/*`（需要密碼）
- **查詢 Tag（球拍主用）**：掃 QR Code 會開啟 `/{ID}`（或首頁輸入 ID）

---

## 2 穿線師流程（建立 Tag）

### 2-1 建立新 Tag

1. 打開 PicoTag 網站
2. 進入建立新 Tag 頁面：`https://{你的網域}/admin/new`

---

### 2-2 填寫資料

依照頁面欄位填入資訊：

- 日期（Stringing date）
- 張力（Tension）
- 線材（String / String info）
- 球拍型號（Racket / Racket info）
- 穿線方式（Pattern）
- 其他備註（Notes）
- 密碼功能（Delete/View/Remarks password）

> 小提醒：  
> - 張力可以只寫一個值，也可以寫主線(Main)/橫線(Cross)（例如 `50/48` 或 `25/27-25`）  
> - 有些欄位是自由輸入，照你習慣記錄即可

---

### 2-3 產生 Tag 與 QR Code

1. 填寫完成後按「Generate Tag ID & QR Code」完成新增
2. 系統會產生：
   - 一組 **Tag ID**
   - 一張 **QR Code**
   - 一個可分享的 **URL**

---

### 2-4 如何使用標籤

1. 點「Download QR Code Label」下載標籤圖檔
2. 建議貼在：
   - 網球拍 - 拍底內側（throat inside）
   - 羽毛球拍 - 握把底蓋（cap）

貼紙建議：
- **18mm 標籤帶**（最簡單、美觀）
- **一般印表機**（印列印後裁切貼上）

---

## 3 球拍掃描查詢

### 3-1 掃 QR Code

用手機相機或 QR Code App 掃描貼紙上的 QR Code，即可開啟 Tag 頁面。

---

### 3-2 分享與複製連結

你可以把 Tag URL 分享給朋友或存到筆記：

- 點「Copy URL」複製連結
- 貼到 LINE / WhatsApp / 記事本

---

## 4 特殊功能

### 4-1 新增/更新備註（Remark）

建立 Tag 時如果有設定密碼，就可在查詢 Tag 頁面新增/更新備註：

1. 在 Tag 頁找到 Remark 區塊
2. 輸入內容與密碼後按 Save

備註建議寫什麼：
- 打了幾次後的手感（彈、控、硬、震）
- 斷線位置與原因
- 下次想嘗試的張力/線材

---

### 4-2 設定查看保護（View protection）

如果你不希望任何人掃到就能看，在建立 Tag 時可以啟用「View protection」功能：

---

### 4-3 設定刪除密碼（Delete password）

提供「Delete password」來保護刪除操作：

- 已設定：刪除 Tag 時需要輸入刪除密碼
- 未設定：前台不提供刪除功能；若你是站點管理者，請到管理後台刪除該筆資料

---

### 4-4 切換語言

可以在網站右上角切換語言（例如 `en / zh-TW / ja / ko`）。

---

## 5 後台功能（Admin）

> 只有「站點管理者 / 穿線師」需要用到後台。  
> 後台入口在：`https://{你的網域}/admin/`（需要密碼驗證）

後台主要有 5 個頁面：

- **建立標籤（Create Tag）**：建立新的 Tag 
- **參考清單（Reference Lists）**：管理建立 Tag 時的下拉清單
- **紀錄（Records）**：查看/搜尋/匯出所有 Tag 紀錄
- **系統（System）**：查看版本與環境、D1/KV 狀態、初始化資料庫
- **網站（Site）**：個人化前台顯示（品牌、簡介、背景、頁尾連結）

---

### 5-1 參考清單（Reference Lists）

用途：讓建立 Tag 時可以自動比對，產生建議的下拉快速選擇，減少手打與拼字錯誤。  
位置：`/admin/reference`

可管理的清單包含：

- 羽毛球：球拍（Racket）  / 穿線法（Pattern） / 球線（String）
- 網球：球拍（Racket）  / 穿線法（Pattern） / 球線（String）
- 通用：機台（Machine）/ 穿線師（Stringer）

常用功能：

- **Add / 新增**：加入單筆項目
- **Batch add / 批次新增**：一次貼上多行文字，快速加入多筆
- **Save / 儲存**：修改後一定要按 Save 才會寫入（未儲存會提示 *Unsaved changes*）
- **Export JSON / Import JSON**：匯出備份、或把另一個站點的清單匯入

> 小提醒：Reference 屬於「加速建立 Tag 填寫工具」，不是必填。

---

### 5-2 紀錄（Records）

用途：集中查看所有 Tag 紀錄、快速搜尋、匯出 CSV。  
位置：`/admin/records`

常用功能：

- **搜尋（Search）**：依關鍵字快速找紀錄
- **分頁（Prev / Next）** 與 **每頁筆數（Per page）**
- **匯出 CSV（Export CSV）**：  
  - 內建快速選擇：本月 / 上月 / 最近 7 天 / 最近 30 天  
  - 或自訂日期區間（From / To）
- **匯出本頁 Tag IDs（Export IDs (page)）**：常用於批次列印標籤或整理清單

列表欄位通常包含：

- Tag ID（通常附「複製」按鈕）
- Protection（是否啟用查看保護）
- Tag name / Owner（依站點設定）
- Tension（張力）
- Created（Tag 建立時間）
- Actions（開啟 Tag、管理/更新等）

---

### 5-3 系統（System）

用途：確認系統是否正常、查看版本與環境資訊、初始化資料庫。  
位置：`/admin/system`

常見區塊：

- **Build Info**：Version、Build Time、Project GitHub、License
- **KV Status (Lists)**：顯示清單名稱與項目數量
  - 列出清單：`RACKET`、`PATTERN`、`STRING`、`MACHINE`、`STRINGER`
- **D1 Status (Tables)**：顯示資料表與筆數  
  - 列出資料表：`records`
- **Initialize Database**：首次架設時用來建立資料表（通常只需要做一次）
- **Environment Variables**：顯示網站常用設定（例如 `APP_ORIGIN`、`DEFAULT_LANG`、`TURNSTILE_SITEKEY`）

---

### 5-4 網站（Site，個人化設定）

用途：調整前台顯示與網站資訊（不需要改程式碼）。  
位置：`/admin/site`

常見設定：

- **Website**：網站/店名
- **Intro**：簡介標題與文字、簡介圖片 URL
- **Background**：背景圖片 URL
- **Footer**：頁尾連結

修改後按 **Save** 儲存。

以上就是 PicoTag 的基本使用流程
