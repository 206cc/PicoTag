## 1 Prerequisites

### 1-1 Tools you need

- Windows + PowerShell
- Node.js (LTS)
- Wrangler (Cloudflare CLI)

---

### 1-2 What this guide assumes

- You’ve already read the deployment guide and know how to set up Cloudflare Pages / KV / D1 / Turnstile.
- You have successfully deployed PicoTag once, and the website works normally.

---

## 2 Where to edit files (project structure)

> This guide uses the “download the ZIP from GitHub Releases and extract it” workflow: simply edit files inside the extracted `PicoTag` folder.

### 2-1 Download the ZIP and extract it

1. Go to the GitHub project **Releases** and download the version ZIP you want (e.g. `PicoTag_v1.0.2.zip`)  
2. Extract it to your PC, for example: `C:\PicoTag`

> Tip: After extracting, make sure you can see `index.html` directly under `C:\PicoTag` (avoid having an extra nested folder).

---

### 2-2 Files you’ll commonly edit

PicoTag is mainly a set of **static website files**. Common locations:

- `index.html`: the Tag view page (what users see after scanning the QR code)
- `admin/new`: the “Tag creation page” page (path may vary depending on your version)
- `admin/`: admin pages (system / records / site / reference…)
- `assets/`: JS / CSS / i18n / version.json and other resources
  - `assets/js/`: main front-end logic
  - `assets/css/`: styles
  - `i18n/`: language JSON files

> After you edit files, redeploy in the next chapter to publish your changes.

---

## 3 Redeploy to Cloudflare Pages (publish your changes)

Whenever you finish editing and want to update the live site, redeploy using the same command:

1. In PowerShell, go to the extracted PicoTag folder
2. Run `dir` and confirm you can see `index.html`  
   - If you don’t see `index.html`, you’re probably one level above. Use `cd` to enter the correct folder.
3. Run the deploy command (this uploads the current folder to Cloudflare Pages)

```powershell
wrangler pages deploy . --project-name picotag-demo
```

> Tip: Replace `picotag-demo` with your own Cloudflare Pages project name.

> **Important**: If you changed **Variables / Bindings** in the Cloudflare Pages dashboard, you must **redeploy** before the live environment will use the new settings.

After deployment finishes, refresh your website in the browser to confirm your changes are live.

---

That’s the PicoTag workflow: **edit → redeploy → live**.
