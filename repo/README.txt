PicoTag Release Package (v1.0.2)

PicoTag is a lightweight QR-code tagging system for badminton and tennis racket stringing records.
It lets stringers generate a tag ID / QR label, attach it to a racket, and allow players to view the stringing info later by scanning the QR code—without requiring user accounts.

This ZIP is a ready-to-deploy build for Cloudflare Pages (Pages Functions included).
You can deploy it without building from source.
